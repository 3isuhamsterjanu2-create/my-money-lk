MY MONEY LK - FINAL PWA PROTOTYPE

Files:
- index.html      Main app
- manifest.json   Installable web-app metadata
- sw.js           Offline cache
- icon.svg        App icon

To test:
Open index.html in a browser.

To install as a phone app:
Host these files on a secure HTTPS website, then use the browser's
"Add to Home Screen" / "Install App" option.

This prototype stores data locally in the browser and does not connect
to bank accounts or financial institutions.
